## 3. 사용자에게 아직 물어봐야 하는 것 (착수 전 확정 필요)

1. **진행 단계에 지급/승인 단계가 필요한가?**
   원본 11단계는 보조금 지급 절차. 모두의창업 축은
   `그룹 개설 → 멘티 등록 → 멘토 배정 → 컨설팅 1~4회 → 평가서 → 종료` 로 보이는데,
   센터의 **승인 게이트**가 실제로 있는지 확인 필요.
2. **평가서(`evaluation_report`)는 멘티당 1건인가, 회차마다인가?**
   단일본이면 `0045` 유니크 인덱스 조건에 반드시 추가해야 함
   (원본에서 이걸 안 걸어 보고서가 5건까지 쌓인 사고가 있었음).
3. **컨설팅 유형(mode)의 정확한 목록과 단가**, 그리고 **사업그룹별로 단가가 다른지.**
4. **정산 주기** — 월 단위인가, 사업그룹 종료 시점인가, 회차 완료 즉시인가.
5. **정산 인정 기준** — 회차를 '완료'로 치는 조건(보고서 등록? 운영진 승인?).
6. **사업그룹 3~5개의 실제 이름과 승계 관계** (어느 그룹 → 어느 그룹).
