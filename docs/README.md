# 문서

이 폴더는 설계·시공 프롬프트 원본에서 추출한 참조 문서를 담습니다.

| 파일 | 원본 | 용도 |
|---|---|---|
| `design-v1.0.md` | 설계문서 v1.0 (.docx) | 사업 개요·워크플로우·DB·역할·화면 명세. 최상위 진리. |
| `step-prompts.md` | 클로드 코드 단계별 프롬프트 (.docx) | 15단계 초기 구축 프롬프트. 각 단계 완료 후 다음 프롬프트 참조. |

## 원본 (.docx) 위치

- 리포에 커밋되지 않았습니다. 사용자 로컬 및 최초 세션 업로드에 보관됩니다.
- 서식(표·이미지 포함) 정확한 재현이 필요하면 원본 파일을 요청하세요.

## 갱신 정책

- 설계 변경이 발생하면 **먼저 이 폴더의 .md를 수정**하고, 프로젝트 루트 `CLAUDE.md`에도 반영합니다.
- 12단계 워크플로우·역할 권한·필수서류 규칙 변경은 반드시 이 문서와 코드가 동시에 갱신되어야 합니다.
