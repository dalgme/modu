## 1. 상시 작업 원칙 (모든 세션에 적용)

첫 프롬프트에서 전달받아 `CLAUDE.md` 에 고정된 규칙이다.

1. 추측하지 말고 실제 파일을 읽고 판단할 것.
2. 코드 변경 후 `npm run typecheck` / `lint` / `build` 3종을 모두 통과시킬 것 (P4 이후 `npm run test` 포함 4종).
3. `case_status` 나 `doc_key` 를 바꿀 때는 UI 버튼 활성 조건과 서버 액션의 상태 게이트를 반드시 함께 수정할 것.
4. 단일본 `doc_key` 는 반드시 DB 유니크 인덱스로 강제할 것.
5. 정산 금액은 화면 표시액과 확정 저장액이 같은 함수에서 나오게 할 것.
6. 환경변수 값은 절대 리포에 커밋하지 말 것. 원본 restart 의 `.env` 값을 복사하지 말 것.
7. 작업은 지정 브랜치에서만, PR 은 요청 시에만.
