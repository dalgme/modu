# 모두의창업 플랫폼 — 기획 정리

> 정리일 2026-09-08 · 대상 리포 `dalgme/modu` · 브랜치 `claude/modu-platform-audit-tutute`
> 원본 뼈대 `dalgme/restart`(재기지원사업 운영관리 플랫폼)를 복제해 "모두의창업" 사업용으로 개조한 결과를 기획 관점에서 정리한 문서다.
> 상세 설계 원문은 `docs/MODU-DESIGN.md`, 세션 규칙은 `CLAUDE.md`.

## 1. 사업 개요

| 항목 | 내용 |
|---|---|
| 사업명 | 모두의창업 |
| 발주·승인 | 세종창조경제혁신센터 (화면 표기 "발주처", 행사 설정에서 기관명 등록) |
| 운영 총괄 | (주)렛츠 (화면 표기 "운영사", 행사 설정에서 기관명 등록) |
| 한 줄 정의 | 참여 **멘티와 멘토를 1:1로 연결·배정**하고, **멘토링 운영과정(회차·보고서·관찰의견서·정산)** 을 관리하는 플랫폼 |
| 확장 요건 | 같은 운영방식을 **계정 추가만으로 여러 행사에 복제**할 수 있어야 한다 → 한 배포 안의 행사(`programs`) 계층 |

### 주체별로 얻는 것
| 주체 | 시스템에서 얻는 것 |
|---|---|
| 발주처(센터) | 멘토별·멘티별 실시간 진행현황, 정산 확인(종결 확정), 리포트 |
| 운영사(렛츠) | 사업그룹 개설, 멘토 배정·중간 교체, 회차·보고서 검수, 관찰의견서 검수, 정산 확정·지급 품의, 각종 설정 |
| 멘토 (약 80명) | 담당 멘티 컨설팅 회차 등록(웹 작성/업로드·사진), 관찰의견서, 종결 요청, 추가 회차·중도 종료 요청, 정산 내역 확인 |
| 멘티 (약 400명) | 본인 진행현황, 회차 확인 서명, 만족도 조사, 멘토 변경 요청, 필수서류·자유서류 제출 |
| 플랫폼 통합관리자 | 행사 개설·복제·종료, 전 행사 계정 통합 관리, 플랫폼 관리자 지정, 통합 감사로그, 시스템 상태 |

## 2. 역할과 계정 정책

| 역할 키 | 화면 표기 | 인원 | 비고 |
|---|---|---|---|
| `institution` | 발주처 (행사 설정의 발주 기관명) | 소수 | 열람·정산 확인 |
| `nextlab` | 운영사 (행사 설정의 용역사 기관명) | 소수 | 운영 총괄. 역할 키는 원본 그대로 유지 |
| `mentor` | 멘토 | 약 80 | 회차·관찰의견서 |
| `mentee` | 멘티 | 약 400 | 서명·설문·서류 |
| (플래그) `is_platform_admin` | 플랫폼 통합관리자 | 1~2 | 역할 enum 을 늘리지 않고 `users.is_platform_admin` 로 부여 |

- **셀프 가입 없음.** 운영사가 계정 발급 → 임시 비밀번호(멘티는 휴대폰 번호) → 최초 로그인 시 변경 강제 + 개인정보 동의.
- **한 계정은 여러 행사·여러 그룹에 귀속**될 수 있다(`program_members`, `support_type_members`, 멘티는 케이스로 그룹 귀속). 역할은 계정 전역으로 하나.
- **통합 로그인** `/login` → 허브 `/hub` 에서 활성 행사 배너 → 그룹 배너. 활성 행사가 1개면 자동 진입, 그룹이 1개면 그룹까지 자동 진입. 상단에 `행사명 › 그룹명` 표시.
- 플랫폼 통합관리자는 상단 보라색 배지가 항상 뜨고, 어느 행사든 운영사 화면에 들어갈 수 있다(모든 행위는 실제 신원으로 감사 기록).

## 3. 핵심 운영 흐름 (사용자 답변 1 을 그대로 상태머신으로)

```
[운영사] 멘티 등록 ──▶ 멘토 배정 ──▶ [멘토] 회차 등록 ×N (일시·장소·온/오프·내용·사진, 웹작성 또는 업로드)
                                          │   멘티: 회차 확인 서명(정책) · 멘토 서명 자동 부착(정책)
                                          ▼
                              [멘토] 관찰의견서 작성 + 종결 요청
                                          ▼
                     [운영사] 검수 ─ 보완 요청 ⇄ ─ 승인 = 정산 확정 스냅샷 → 지급 대기
                                          ▼
                     [운영사] 지급 품의 편성·제출 ──▶ [발주처] 정산 확인 = 종결 확정
       ※ 멘티 중도 종료 / 멘토 자진·강제 중도 종료 → 이행 회차 부분 정산, 잔여 회차는 타 멘토 재배정
```

멘티 부가 기능: 회차 서명 · 만족도 조사(종결 요청 이후 1회, 그룹별 표준양식) · 멘토 변경 요청(운영사 수락 시 교체).

## 5. 확정 수치·정책 요약

| 항목 | 값 | 어디서 바꾸나 |
|---|---|---|
| 단가 | 온라인 80,000원/회 · 오프라인 100,000원/회 | 운영 설정 → 단가·한도 (적용일 이력) |
| 1일 상한(같은 멘티·같은 날) | 온라인 240,000 · 오프라인 300,000 · 회차 ≤ 3 | 운영 설정 |
| 멘토 1일 최대 | 3건(멘티) | 운영 설정 |
| 기본 회차 | 그룹별 4회(3~4) + 승인된 추가 회차 | 그룹 설정, 요청함 |
| 원천징수 | 기타소득 8.8% (필요경비 60%, 세율 20%, 지방세 10%, 과세최저한 5만원) / 사업소득 3.3% / 없음 | 행사 정산 설정, 그룹 일괄, 그룹 내 멘토별 |
| 정산 단위 | 케이스 × 멘토, 종결 검수 승인 시 확정 스냅샷 | 자동 |
| 종결 게이트 | 멘티 서명 필수·필수서류 완료 = 기본 꺼짐 | 운영 설정 → 종결 게이트 |
| 보고서 서명 정책 | 멘티 확인 서명(기본 켬) · 멘토 자동 서명(기본 끔), 양식에 서명 컬럼 있을 때만 | 운영 설정 → 정책 / 그룹 |
| 만족도 | 종결 요청 이후 1회, 정산 게이트 아님 | 운영 설정 → 만족도 |
| AI 매칭 | 객관 점수(태그 겹침·지역·유형·부하) + 모델 정성 근거(선택). 자동 배정 없음 | `ANTHROPIC_API_KEY` 유무 |
