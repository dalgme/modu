모두의창업 멘토링 플랫폼
이렇게 사용하세요

멘티(창업팀)와 멘토를 1:1로 연결하고, 멘토링의 시작부터 수당 지급까지 한 곳에서 관리하는 서비스입니다.

1누가, 무엇을 하나요?

이 플랫폼에는 네 종류의 사용자가 있습니다. 로그인하면 자기 역할에 맞는 화면만 보입니다.

발주처진행현황을 실시간으로 확인하고, 정산을 최종 확인합니다
운영사 담당자행사 전체를 운영합니다 — 이 안내서의 주인공!
멘토 (약 80명)담당 멘티를 컨설팅하고 회차·보고서를 등록합니다
멘티 (약 400명)멘토링을 받고, 보고서를 확인·서명합니다

2전체 흐름 한눈에 보기

멘토링 한 건은 아래 순서로 흘러갑니다. 색깔 배지는 그 일을 하는 사람입니다.

1명단 등록멘토·멘티를 이름/연락처로 등록 (엑셀 가능)운영사
→
2안내 문자 발송로그인 방법을 문자로 안내운영사
→
3로그인 시작임시 비밀번호(휴대폰 번호)로 첫 로그인 → 비밀번호 변경멘토 멘티
→
4멘토 배정AI 추천을 참고해 멘티마다 멘토 1명 확정운영사
5멘토링 진행① 일정(계획/실행) 등록 → ② 보고서 등록 — 회차마다 반복멘토
→
6멘티 확인 서명보고서 내용을 확인하고 서명멘티
→
7종결 검수모든 회차 완료 → 관찰의견서 → 검수 승인운영사
→
8정산·지급수당 자동 계산 → 지급 품의 → 발주처 확인으로 종결운영사 발주처
💡 수당은 자동으로 계산됩니다. 멘토가 회차를 등록하면 온라인/오프라인 단가로 시스템이 집계하므로, 지급청구서를 따로 쓸 필요가 없습니다. 단, 보고서까지 등록된 회차만 수당으로 인정됩니다.

3시작하기 — 접속 주소와 총괄담당자 등록

플랫폼 접속 주소 (로그인) modu-dalgmes-projects.vercel.app 이미 계정이 있는 모든 사용자는 여기서 로그인합니다.
운영사 총괄담당자 등록 (최초 1회) modu-dalgmes-projects.vercel.app/register/operator 확인코드: letsedu0902
총괄담당자 등록은 3단계면 끝납니다
1등록 페이지 열기위의 /register/operator 주소로 접속
→
2정보 입력이름·직위·이메일(아이디)·휴대폰·비밀번호 + 확인코드
→
3바로 로그인방금 만든 아이디·비밀번호로 로그인 → 운영사 화면 시작
⚠️ 확인코드는 운영사 내부에서만 공유하세요. 코드를 아는 사람은 운영사 총괄담당자로 등록됩니다. 코드 변경·중지는 플랫폼 통합관리자가 할 수 있습니다.

4운영사 담당자의 업무 6가지

로그인하면 상단 메뉴에서 아래 화면들을 오가며 일합니다. 순서대로 따라 하면 됩니다.

① 행사 기본 설정 운영 설정

기관명·사업그룹·컨설팅 단가(온라인/오프라인)·회차 수를 확인합니다. 문자 발송을 쓰려면 운영 설정 → 문자 API 에 문자 서비스 키를 등록하세요.

② 멘토·멘티 명단 등록 회원 관리 멘티 등록

이름·이메일·연락처·소속·직위만으로 먼저 등록합니다. 인원이 많으면 엑셀 일괄 등록! 멘티는 등록 즉시 확정, 멘토는 Pool(대기) 상태로 시작합니다.

③ 로그인 안내 문자 회원 관리

명단에서 회원을 체크하고 [로그인 안내 문자 발송]을 누르면 접속 주소와 임시 비밀번호(본인 휴대폰 번호) 안내가 문자로 나갑니다. 발송 여부가 명단에 표시됩니다.

④ 멘토 배정 케이스 상세

멘티(케이스)마다 AI 추천 카드를 참고해 멘토를 클릭으로 배정합니다. 배정되면 그 멘토는 그 멘티에 대해 "확정"이 됩니다. 중간 교체도 가능하고 회차는 이어집니다.

⑤ 진행 관리 대시보드 요청함 조사

회차 진행·보고서·서명 현황을 대시보드에서 보고, 추가 회차·멘토 변경 요청은 요청함에서 승인/반려합니다. 만족도·선호도 조사도 개설해 실시간 분석할 수 있습니다.

⑥ 검수와 정산 케이스 상세 정산 관리

멘토가 종결을 요청하면 보고서·관찰의견서를 검수해 승인합니다. 승인 순간 수당이 확정 계산되고, 지급 품의로 묶어 제출 → 발주처가 확인하면 종결됩니다.

5추가 담당자·옵저버 등록하기

총괄담당자(PL)는 함께 일할 운영사 담당자와 열람 전용 옵저버 계정을 직접 만들고 관리합니다.

1회원 관리 열기상단 메뉴 회원 관리 → "회원 계정 발급"
→
2역할·등급 선택역할 = 운영사, 등급을 PM/부PM/옵저버 중 선택 + 직위 입력
→
3안내하기임시 비밀번호(휴대폰 번호)를 전달하거나 안내 문자 발송

✏️ 수정·삭제도 같은 화면에서: 각 회원의 [정보 수정]으로 이름·연락처·직위·등급을 바꾸고, 비밀번호 재설정·비활성화·소속 해제도 할 수 있습니다.

등급어떤 사람?할 수 있는 일
PL (메인 담당)총괄담당자모든 기능 — 설정·회원·배정·검수·정산·문자 전부
PM실무 담당자대부분 가능 / 단가·정산 설정과 민감정보 관리는 불가
부PM보조 담당자일상 운영 가능 / 품의 제출·설정 변경은 불가
옵저버열람만 하는 사람화면 열람과 리포트만 / 등록·수정·발송 전부 불가
💡 등급은 행사마다 따로 정해집니다. 같은 사람이 이 행사에서는 PL, 다른 행사에서는 PM일 수 있어요. 등급별 세부 권한은 운영 설정 → 담당 권한 에서 행사에 맞게 조정할 수 있습니다.

6멘토와 멘티는 이렇게 씁니다

🧑‍🏫 멘토의 화면

① 문자로 받은 주소에서 로그인(임시 비밀번호 = 휴대폰 번호) → 비밀번호 변경
② 담당 멘티 카드에서 회차 등록(1단계) — 날짜·시간·방법·참가자를 클릭으로 선택 (미리 계획 등록도 가능)
③ 멘토링 후 보고서 등록(2단계) — 웹으로 쓰거나 파일 첨부
④ 모든 회차가 끝나면 관찰의견서 작성 → 종결 요청
⑤ 수당은 자동 집계 — 정산 내역 에서 확인

🚀 멘티의 화면

① 문자로 받은 주소에서 로그인 → 비밀번호 변경
② 내 멘토링 진행현황과 회차 일정을 확인
③ 멘토가 보고서를 올리면 내용 확인 후 서명
④ 필요한 서류 제출, 만족도 조사 참여
⑤ 멘토 변경이 필요하면 변경 요청 가능

7자주 묻는 질문

비밀번호를 잊어버렸어요

로그인 화면의 비밀번호 재설정을 이용하거나, 운영사 담당자에게 요청하면 회원 관리 에서 임시 비밀번호(휴대폰 번호)로 재발급해 줍니다. 첫 로그인 때 새 비밀번호로 바꾸게 됩니다.

안내 문자가 발송되지 않아요

운영 설정 → 문자 API 에 행사용 문자 서비스(솔라피) 키와 발신번호가 등록되어 있는지 확인하세요. "내 휴대폰으로 테스트" 버튼으로 바로 점검할 수 있습니다.

회차를 등록했는데 수당에 안 잡혀요

회차는 2단계(보고서 등록)까지 마쳐야 수당으로 인정됩니다. 1단계(일정)만 등록된 "계획" 회차는 진행 후 [보고서 등록] 버튼으로 완료해 주세요.

같은 사람이 다른 행사에도 참여할 수 있나요?

네. 계정은 하나로 유지하면서, 행사마다 다른 역할(예: A 행사 멘토, B 행사 멘티)을 가질 수 있습니다. 회원 관리 → 기존 계정을 이 행사에 추가 를 이용하세요.

옵저버가 실수로 데이터를 바꿀 수 있나요?

아니요. 옵저버는 화면 상단에 열람 전용 안내가 표시되고, 등록·수정·발송 버튼을 눌러도 서버에서 차단됩니다.
