🚀 모두의창업 멘토링 플랫폼

멘티(창업팀)와 멘토를 1:1로 연결하고, 멘토링의 시작부터 수당 지급까지 한 곳에서 관리합니다.
위의 탭을 눌러 역할별·기능별 사용법을 살펴보세요.

이 플랫폼에는 네 종류의 사용자가 있고, 로그인하면 자기 역할의 화면만 보입니다.

🎬 총괄담당자 등록 — 3장짜리 슬라이드

1️⃣

등록 페이지 열기

위의 /register/operator 주소로 접속합니다. 이 창구는 행사당 1명만 쓸 수 있는 1회용 문입니다.

2️⃣

정보 입력

이름 · 직위 · 이메일(로그인 아이디) · 휴대폰 · 비밀번호를 직접 정하고, 확인코드를 입력합니다.

3️⃣

바로 로그인 → 코드 자동 닫힘

등록이 끝나면 확인코드는 자동으로 소진됩니다. 방금 만든 아이디로 로그인하면 운영사 화면이 열립니다. 추가 담당자는 [회원 관리]에서 발급하세요.

⚠️ 확인코드는 1회용입니다. 총괄담당자 1명이 등록하면 자동으로 닫히므로 반드시 총괄담당자 본인이 사용하세요. 재오픈(새 코드)은 플랫폼 통합관리자가 합니다.

📋명단 등록

운영사가 멘토·멘티를 이름/이메일/연락처/소속/직위만으로 먼저 등록해 두고, 안내 문자를 보내 로그인하게 하는 "명단 우선" 방식입니다. 회원 관리 메뉴에서 합니다.

💻 웹에서 한 명씩

멘티 등록 에서 기업(팀)명·대표자·연락처·사업그룹을 입력하면 케이스 1건이 만들어지며 즉시 확정됩니다. 멘티 계정도 자동 발급됩니다(임시 비밀번호 = 휴대폰 번호).

📊 엑셀로 한 번에

회원 관리 → 엑셀 일괄 등록 → 템플릿 다운로드 → 채워서 업로드 → 미리보기에서 오류 확인 → 확정. 이미 있는 계정(휴대폰/이메일 일치)은 새로 만들지 않고 이 행사에 연결만 합니다.

👥팀이라면? 케이스 상세의 팀 정보 패널에서 아이템명·아이템 설명·팀원 명단(대표 표시 포함)을 등록합니다. 팀원도 멘토링에 참여자로 기록될 수 있어요.
💡 멘티는 등록과 동시에 "확정"입니다. 등록 즉시 멘토 배정 대상이 됩니다.
💻 웹에서 한 명씩

회원 관리 → 회원 계정 발급 에서 역할 = 멘토로 발급합니다. 이메일·이름·휴대폰·소속·직위를 입력하면 끝.

📊 엑셀로 한 번에

멘토 템플릿에는 전문분야·업종·지역·경력 칸이 있습니다. 이 정보가 AI 추천의 재료가 되니 되도록 채워 주세요.

🏊멘토는 "Pool(대기)" 로 시작합니다. 등록만으로는 미확정이고, 멘티에게 배정되는 순간 그 멘티에 대해서만 "확정"이 됩니다. 명단에서 Pool/확정 배지로 구분됩니다.

🏷️ 임의 컬럼 — 나만의 분류표 만들기

멘티/멘토 탭에서 임의 컬럼(예: "1차 배정군", "우선관리")을 최대 8개까지 만들 수 있습니다. 각 회원 칸에 값을 입력하면 카테고리 마크처럼 쓸 수 있어요.

✏️ 회원 정보 수정

각 회원의 [정보 수정]을 누르면 이름·휴대폰·이메일(로그인 아이디)·소속·직위를 고칠 수 있습니다. 비밀번호 재설정(임시 비밀번호 재발급)·비활성화·소속 해제도 같은 곳에서.

🔁 다른 행사 사람 데려오기

기존 계정을 이 행사에 추가 로 다른 행사의 계정을 이 행사에 소속시킵니다. 역할은 행사마다 따로 — 저쪽에선 멘토, 이쪽에선 멘티도 가능합니다. 계정은 하나!

🖱️ 사용 순서

📇

1. 프로필 채우기

케이스 상세에서 멘티 프로필(업종·창업단계·지역·필요분야 키워드)을 입력합니다. 멘토는 본인이 내 프로필 에서 전문분야를 등록하고, 운영사가 엑셀 등록 때 채워둘 수도 있습니다.

✨

2. 추천 생성

케이스 상세의 AI 추천 카드에서 [추천 생성]을 누르면 몇 초 안에 상위 멘토 후보들이 점수·근거와 함께 나타납니다.

🔍

3. 카드 비교

각 후보의 점수 구성(키워드/지역/부하)과 AI 설명을 읽고 비교합니다. 추천이 마음에 안 들면 목록의 다른 멘토를 직접 골라도 됩니다.

🤝

4. 클릭으로 배정

[이 멘토로 배정]을 누르면 끝. 배정 이력과 어떤 추천을 채택했는지가 기록으로 남습니다. 중간에 멘토를 바꿔도 회차는 이어집니다.

💡 추천 품질을 높이는 열쇠는 키워드입니다. 운영 설정 → 키워드 사전 에 행사에서 쓸 분야·업종·지역 키워드를 정리해 두면, 멘토와 멘티가 같은 단어로 프로필을 채우게 되어 매칭이 정확해집니다.

📁 케이스 — 멘티 한 명의 모든 것

멘티(케이스)마다 상세 페이지가 있습니다: 진행 상태, 멘토 배정/AI 추천, 팀 정보, 회차 목록, 관찰의견서, 서류함, 검수·정산 패널까지 한 페이지에서 처리합니다.

👥 회원 명단 — 멘티·멘토·관리자 명단 + 회원 등록

미니탭 4개: 멘티 명단(케이스 진행현황·만족도 생성/완료·비활성 표시) / 멘토 명단(담당·회차·지급액·Pool/확정, 지급서류 제출·수령, 원천징수, 평가 메모, 멘토 서류 일괄 ZIP) / 관리자 명단(운영사·발주처 담당자) / 회원 등록(자격별 폼 + 엑셀 일괄). 모든 명단은 엑셀로 내려받을 수 있고, [화면 보기]로 멘토·멘티 화면에 대행 진입할 수 있습니다.

📮 게시판 — 문의·요청·메시지를 한곳에서

미니탭: 전체 글(제목·발송자·발송일시·확인여부, 발송자별 모아보기) / 멘티 문의 / 멘토·운영 게시판 / 요청함(추가 회차·멘토 변경·중도 종료 승인) / 멘토·멘티 메시지(1:1 대화 모니터링) / 멘토 FAQ. 새 글이 오면 대시보드에 알람이 뜹니다.

📈 조사 — 설문 만들기와 실시간 분석

만족도·사전선호도 등 여러 조사를 행사 전체/그룹/개별 대상으로 기간을 정해 개설합니다. 응답은 플랫폼 안에서도, 문자 링크로도 가능하고 미참여자에게 독려 문자를 한 번에 보낼 수 있습니다.

💰 정산 · 📑 리포트

정산은 [💰 정산 지급] 탭 참고. 리포트에는 라운드(그룹)별 구분 탭과 개요(예산 집행 게이지)·월별 추이·진행현황(멘티/멘토)·잔여 과업(지연 케이스 + 독려 문자)·종합결과리포트(스냅샷, PDF·엑셀·워드·PPT)가 있습니다.

운영사가 검수를 마친 케이스들의 수당을 지급 품의로 묶어 제출하면, 발주처 [정산] 메뉴에 나타납니다.

🧑‍🏫멘토 대시보드 · 기능

담당 멘티를 컨설팅하고 기록하는 화면입니다. 핵심은 "회차 등록은 2단계" — 이것만 기억하면 됩니다.

멘토 화면 — 상단 메뉴
📊 대시보드🗓️ 스케줄💰 정산 내역📇 내 프로필✍️ 내 서명💬 문의·멘티 메시지📖 이용안내
대시보드에는 담당 멘티 카드들이 나란히 — 카드를 누르면 그 멘티의 회차·보고서·요청을 처리하는 상세 화면이 열립니다. 참여할 조사(설문)도 대시보드에 뜹니다.

📝 회차 등록 2단계 — 슬라이드로 따라 하기

🗓️

1단계 ① 일정 잡기

멘티 카드 → [회차 등록]. 날짜는 달력, 시간은 10분 단위 선택(24시간제), 운영시간은 자동 계산됩니다. 미래 날짜로 미리 "계획" 등록도 가능해요.

🖱️

1단계 ② 방법·참가자·장소

온라인/오프라인 버튼, 참가자(멘티 본인·팀원)를 칩 클릭으로 복수 선택, 장소만 직접 입력. 하단 요약 카드에서 선택 내용을 한눈에 확인하고 등록!

📄

2단계 — 보고서 등록

멘토링을 진행한 뒤 그 회차의 [보고서 등록]을 눌러 웹으로 작성(자동으로 양식 PDF 생성)하거나 파일을 첨부합니다. 사진도 함께 올릴 수 있어요.

⚠️

왜 2단계가 중요한가요?

보고서까지 등록된 회차만 수당으로 인정됩니다. 일정만 등록된 "계획" 회차는 정산에 포함되지 않고, 멘티 서명과 종결 요청도 보고서가 있어야 진행됩니다.

🧰 그 밖의 기능

🏁 종결 요청 — 마지막 회차가 끝났다면

모든 회차의 보고서를 등록한 뒤, 관찰의견서(멘티에 대한 종합 평가)를 작성하고 [종결 요청]을 누릅니다. 운영사가 검수해 승인하면 수당이 확정됩니다.

➕ 추가 회차 · 🔄 중도 종료 요청

회차가 더 필요하면 사유와 함께 추가 회차를 요청하고, 사정상 계속하기 어렵다면 중도 종료를 요청합니다. 모두 운영사 승인 후 진행됩니다.

✍️ 내 서명 · 📇 내 프로필

내 서명을 등록해 두면 웹 작성 보고서 PDF에 서명이 자동으로 들어갑니다. 내 프로필(전문분야·지역·경력)은 AI 추천의 재료이니 충실히!

💰 정산 내역 — 지급청구서는 안 씁니다

회차를 등록하면 수당이 자동 집계됩니다(온라인 8만/오프라인 10만 기준, 행사 설정에 따름). 확정·품의·지급 단계도 정산 내역에서 확인되고, 확정 시 문자로 알려드립니다.

🚀멘티 대시보드 · 기능

멘토링을 받는 창업팀의 화면입니다. 확인하고, 서명하고, 제출하는 세 가지가 전부입니다.

👁️확인내 멘토링 진행현황과 회차 일정
✍️서명멘토가 올린 보고서 확인 후 서명
📤제출필수서류 제출 · 조사 참여
🗓️스케줄멘토가 등록한 컨설팅 예약·완료를 달력으로
💬메시지[문의하기]의 멘토 메시지 탭에서 담당 멘토와 1:1 대화

🖱️ 처음 로그인부터 서명까지

📲

1. 문자 받고 로그인

안내 문자의 주소로 접속 → 아이디(이메일 또는 휴대폰 번호)와 임시 비밀번호(본인 휴대폰 번호 숫자)로 로그인 → 새 비밀번호로 변경.

🏠

2. 대시보드 확인

내 멘토가 누구인지, 몇 회차까지 진행됐는지, 지금 해야 할 일(서명 대기·서류·조사)이 카드로 표시됩니다.

✍️

3. 보고서 확인·서명

회차 메뉴에서 멘토가 등록한 보고서를 읽고 [확인·서명]을 누른 뒤 화면에 서명합니다. 서명은 보고서 PDF에 함께 담깁니다. 보고서가 아직 없으면 "등록 대기"로 표시돼요.

📤

4. 서류 제출 · 조사 참여

서류 에서 그룹별 필수서류를 올리고, 만족도 조사 등은 대시보드 카드나 문자 링크로 참여합니다.

🔄 멘토가 나와 맞지 않는다면?

대시보드의 멘토 변경 요청에 사유를 적어 보내면 운영사가 검토 후 새 멘토를 배정합니다. 이미 진행한 회차는 그대로 이어집니다.

👥 팀원도 멘토링에 참여할 수 있나요?

네. 운영사에 팀원 명단을 알려주면 등록되고, 멘토가 회차를 기록할 때 참가자로 선택합니다. 대표가 아닌 팀원의 참여도 기록에 남습니다.

✅종결 검수

멘토링이 끝난 케이스를 운영사가 확인하고 도장을 찍는 절차입니다. 검수 승인 = 수당 확정이므로 이 단계가 품질의 관문입니다.

🚧 종결 전에 자동으로 걸러지는 것들

📄 보고서 없는 회차

계획만 등록된 회차가 하나라도 있으면 종결 요청이 차단됩니다 — "몇 회차 보고서가 없어요"라고 알려줍니다.

📝 관찰의견서

멘티당 1건, 담당 멘토가 작성해야 합니다. 없으면 종결 불가.

✍️ 멘티 서명 (선택 게이트)

운영 설정 → 종결 게이트 에서 켜면 "전 회차 멘티 서명 완료"를 종결 조건으로 만들 수 있습니다.

📎 필수서류 (선택 게이트)

그룹별 필수서류 제출 완료를 조건으로 걸 수도 있습니다. 두 게이트 모두 기본은 꺼짐.

🔄 중간에 멘토·멘티가 그만두면? (부분 정산)

멘토 중도 종료가 승인되면 이미 이행한 회차만 부분 정산되고, 케이스는 재배정 대기가 되어 새 멘토가 잔여 회차를 이어갑니다. 멘티 중도 포기도 이행분만 부분 정산됩니다.

💰정산 지급

지급청구서를 쓰지 않습니다 — 시스템이 회차 기록으로 수당을 자동 계산하고, 운영사는 묶어서 품의만 올립니다.
