모두의창업 — 한글 보고서 PDF 자동 변환 프로그램 (Windows)

[무엇을 하나요]
플랫폼에 올라온 한글(HWP·HWPX) 회차 보고서·관찰의견서를 이 PC 의 정품 한글로 열어 'PDF로 저장'한 뒤
플랫폼에 다시 올립니다. 한글 원본은 그대로 두고, 합본 PDF·제출용 묶음은 이 PDF 를 씁니다.
점검 시각(기본 09:00·12:00·17:00)은 플랫폼 운영 설정 > [한글 PDF 변환] 에서 바꿉니다.

[설치]
1. 이 ZIP 을 PC 의 아무 폴더에 풀어 주세요(바탕화면 등).
2. install.cmd 를 더블클릭합니다. (관리자 권한은 필요 없습니다)
   - 한글이 설치돼 있는지 확인하고, Windows 로그인할 때 자동으로 켜지도록 등록합니다.
3. 설치가 끝나면 압축을 푼 폴더는 지워도 됩니다. 프로그램은 아래 폴더에 있습니다.
   %LOCALAPPDATA%\ModuHwpConverter

[알아 둘 점]
- PC 가 켜져 있고 Windows 에 로그인된 상태여야 변환됩니다. 꺼져 있던 동안 놓친 시각은 켤 때 1회 실행합니다.
- 처음 변환할 때 한글이 '파일 접근 허용' 창을 띄우면 [모두 허용]을 눌러 주세요.
  (한컴 개발자 사이트의 '보안 승인 모듈' DLL(FilePathChecker…dll)을 이 폴더에 넣고 설치하면 창이 뜨지 않습니다)
- 지금 바로 변환하려면 설치 폴더의 run-now.cmd 를 실행하세요. 기록은 converter.log 에 남습니다.
- 암호가 걸린 문서·배포용 문서는 변환되지 않습니다(플랫폼 화면에 실패로 표시).
- config.json 에는 이 PC 전용 연결 키가 들어 있습니다. 다른 사람에게 보내지 마세요.
  PC 를 바꾸거나 키가 새었으면 플랫폼 운영 설정에서 이 PC 를 [연결 해제]하고 새로 등록하세요.

[삭제]
설치 폴더의 uninstall.cmd 를 실행한 뒤 폴더를 지우세요.
